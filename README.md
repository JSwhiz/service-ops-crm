# Service Ops CRM

Внутренняя web-система управления объектами, задачами, сотрудниками, расходниками, подотчетом, чатами и внутренними процессами компании.

## Статус проекта

Проект находится на этапе архитектурной подготовки и запуска foundation-слоя.

## Цели первой версии

- единая база объектов
- ежедневная работа по объектам
- задачи и подтверждения
- табель и зарплатная логика
- разовые заказы
- склад и оборудование
- подотчет и расходы
- внутренние чаты
- аудит и уведомления

## Технологический стек

- Frontend: Next.js + TypeScript
- Backend: NestJS + TypeScript
- Database: PostgreSQL
- Realtime / helper: Redis
- File storage: MinIO (S3-compatible)
- Infrastructure: Docker Compose
- ORM / migrations: Prisma

## Репозиторий

Монорепозиторий:

- frontend
- backend
- infra
- docs
- shared config / types

## Git strategy

- `main` — стабильная ветка
- `dev` — рабочая интеграционная ветка
- `feature/*` — ветки задач

## Примечание

Структура репозитория и рабочая инфраструктура будут добавлены на следующих этапах.
