# Product branding

The repository currently uses the working product name **Service Ops CRM**.

A dedicated branding pass is intentionally deferred. It should define, at minimum:

- final product name;
- positioning statement and short tagline;
- logo / mark and repository social preview;
- naming conventions for the application, repository and deployment artifacts;
- visual identity alignment with the approved product design system;
- public-facing attribution and portfolio presentation rules.

Until that work is approved, **Service Ops CRM** remains the canonical working name and should not be replaced ad hoc in code or documentation.
