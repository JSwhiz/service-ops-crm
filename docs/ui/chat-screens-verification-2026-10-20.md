# Чаты: дополнительные экраны и вложения — 20.10.2026

## Область работы

Локальный интерфейс `/chats`, светлая палитра CRM. Telegram использован как референс взаимодействий: плоские строки людей, компактная шапка, выбор участников перед названием группы, боковая панель поиска/файлов. Системные комментарии объектов не объединялись с чатами. Производственный сервер не изменялся.

## Пройденные экраны

1. **Личный чат — проверен.** Компактное окно, поиск собеседника, аватары, выделение выбранного человека; пустой выбор блокирует открытие. Шапка, список и действия разделены, клавиатурный фокус попадает в поиск.
2. **Группа — проверена до отправки.** Выбор участников → «Далее» → название и итоговый список. Проверены поиск, выбор и переход между шагами; группа без названия не создаётся. Новые чаты в ходе браузерного обхода не создавались.
3. **Редактирование — проверено без сохранения.** Одно поле названия и согласованная группа «Отмена / Сохранить», без технических пояснений. Не менялись названия существующих чатов.
4. **Информация и участники — проверены.** Название, количество участников, поиск людей, роли; быстрые переходы к поиску, медиа и файлам. Добавление участников остаётся доступным только при существующей capability и для группы.
5. **Пересылка — проверена до отправки.** Поиск доступного чата и выбор строкой вместо нативного select. Браузерная проверка не отправляла сообщение; реальная пересылка и ограничения проверены интеграционным тестом.
6. **Архив — проверен.** Название и предпросмотр получили пространство за счёт удаления лишней колонки даты. Кнопка возврата помещается в строку. Восстановление/скрытие данных в браузерном обходе не выполнялось.
7. **Поиск внутри чата — проверен.** Кнопка в шапке и ⌘F; панель внутри переписки, подсветка, автор и дата, переход к конкретному сообщению. В браузере найдено и открыто сообщение от 05.05.2026. Backend фильтрует комнату до ограничения результатов; предусмотрена курсорная догрузка, а не фильтрация первых глобальных результатов.
8. **Медиа и файлы — проверены.** Вкладки, поиск по именам в просмотренной части истории, просмотр/скачивание и переход к сообщению. История загружается отдельными порциями по 100 сообщений с явной кнопкой загрузки предыдущей части; список не выдаётся за полный, пока остаются предыдущие сообщения.
9. **Прикрепление — проверено частично.** ⌘V добавил PNG из буфера в черновик. ⌘ShiftU открыл выбор файла, JPEG появился в черновике. Оба проверочных вложения удалены без отправки, буфер восстановлен. Ctrl используется теми же обработчиками; отдельного Windows-прогона не было.
10. **Перетаскивание — реализовано, ручной перенос из Finder не прогонялся.** Обработчики входа/выхода/сброса, подсказка области приёма, предотвращение открытия файла браузером, добавление в черновик и отсечение повторного выбора одного файла. При отсутствии права записи файлы не добавляются. Это не подтверждение физического drag-and-drop на устройстве.

## Адаптивность и клавиатура

- Проверены 390×844, 768×1024, 1280×720 и 1600×900. На проверенных состояниях ширина/высота документа совпали с окном; отсутствовала внешняя горизонтальная прокрутка.
- На телефоне диалоги занимают весь экран; на компьютере ширина 480 px, длинное содержимое прокручивается внутри окна. Исправлен конфликт размеров/отступов с общим мобильным Dialog.
- Для общих окон использован существующий Dialog: Escape, модальность и удержание фокуса. Поиск и файлы — немодальная панель внутри чата; Escape возвращает фокус в шапку.
- ⌘/Ctrl+F — поиск в текущем чате; ⌘/Ctrl+Shift+U — выбор файла; ⌘/Ctrl+V — вставка изображения/файла в поле сообщения. Enter/Shift+Enter сохраняют прежнее поведение отправки/переноса.
- Новая функция не меняет контроллер прокрутки, realtime ordering/deduplication или правила прочтения.

## Проверки кода

- Frontend и backend TypeScript — успешно.
- ESLint изменённых модулей — успешно; `git diff --check` — успешно.
- `chats.integration.test.ts` — успешно в отдельной временной схеме локальной БД. Добавлены проверки поиска по конкретной комнате, трёх страниц из 55 сообщений без дублей, отсутствия результатов из другой/недоступной комнаты, ограничения по дате вступления.
- Первый запуск интеграционного теста завершён средой сигналом SIGKILL без упавшего assert. Повтор с TS_NODE_TRANSPILE_ONLY и ограничением Node heap 384 MB прошёл; проверки типов отдельно выполнены полностью.
- Миграции, новые права и изменения производственной БД не требовались.

## Наблюдения вне реализованных изменений

- Некоторые имена вложений уже приходят повреждёнными (`Ð…`). Отображение исправно показывает сохранённое имя, но проблема кодировки загрузки/данных здесь не исправлялась.
- Повторяющиеся Bootstrap Founder — реальные записи локального тестового набора, а не нарисованные дубликаты. Список сохраняет различающие логины; данные не удалялись.
- Полная проверка экранным диктором, реальной клавиатурой телефона и физическим перетаскиванием из Finder не проводилась. Это не заключение о полной доступности всех экранов CRM.
