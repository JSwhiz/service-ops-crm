## Версии и воспроизводимость документов

В JSON каждой ячейки есть исходные evidence IDs с реальным observed/limit/run, сохранённые handoff JSON pointers, источники применимости, exact leaf source anchors, late-фазы с получателем/ресурсом и остаточные обязанности. Старые входные документы не перезаписаны.

Реестр версий различает current documentary snapshot и original executed/reviewed frozen cohort. Из 3918 связок в составных manifests 3573 совпадают побайтно, 278 изменены, 67 имеют только текущий адрес без frozen-эпохи. Это **не количество файлов или тестов**, в manifests есть несколько эпох и общие зависимости. Совпадение одного метода не делает весь изменённый граф эквивалентным. Изменение файла само по себе не требует повторения всех его тестов.

Для спорной версии следующий шаг — адресно разобрать изменённый метод/зависимость; новый прогон нужен только если сохранённый результат нельзя обоснованно перенести. Непокрытый реальный потребитель проверяется отдельно, без повторения зачтённого.
