# Golden Path Index

## Объекты
- GP-OBJ-001: создание объекта руководящим кругом
- GP-OBJ-002: управление responsibles/managers/staffing
- GP-OBJ-003: ежедневный объектный цикл — arrival, report, attendance, feed
- GP-OBJ-004: изменение объекта через approval

## Задачи
- GP-TASK-001: создание задачи по объекту
- GP-TASK-002: закрытие задачи через подтверждение

## Табель
- GP-TS-001: attendance -> automatic day value
- GP-TS-002: ручная корректировка с причиной
- GP-TS-003: экспорт месячного табеля в Excel

## Разовые заказы
- GP-OTO-001: создание карточки заказа
- GP-OTO-002: работа по заказу с участниками, расходниками, файлами и задачами
- GP-OTO-003: отдельный табель разового заказа

## Inventory
- GP-INV-001: обычное движение расходников
- GP-INV-002: исключение списания на объект без фото через director-only approval bridge

## Equipment
- GP-EQP-001: выдача/возврат/перемещение оборудования

## Employees-HR
- GP-HR-001: создание employee-карточки
- GP-HR-002: подмена по правилу процесса

## Expenses / accountability
- GP-EXP-001: выдача подотчета
- GP-EXP-002: фиксация расхода
- GP-EXP-003: возврат подотчета выдавшему

## Approvals
- GP-APR-001: создание объекта через правило “внес один — подтвердил другой”
- GP-APR-002: закрытие задачи через approval
- GP-APR-003: изменение объекта и assignments через approval

## Chats
- GP-CHAT-001: профильный чат с unread/read receipts
- GP-CHAT-002: редактирование собственного сообщения в ограниченное окно

## Notifications
- GP-NOT-001: события по задачам
- GP-NOT-002: события по approvals
- GP-NOT-003: события по чатам
