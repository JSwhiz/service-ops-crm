# Локальная приёмка создания объекта и графиков — 2026-10-29

Область: объект → дополнительные сведения → условия оплаты → штатная позиция → группы → плановая смена → подтверждённый факт → действующий табель. Production, DNS, сервер и публикация не затрагивались.

## Подтверждённые правила

- Сезонность включена/выключена. При включении лето/зима определяются по настроенным ежегодным границам; выключение возвращает профиль «По умолчанию». Даты не угадываются.
- Название позиции произвольное; численность необязательна. Условие «Уборка» выбирается в позиции «Уборщица».
- Первый шаблон — 5/2 по дням недели; 2/2 предлагает две группы со сдвигом 2, 1/3 — четыре. Возможны свои последовательности/интервалы и больше двух групп.
- Менеджер выбирает готовые активные условия текущего объекта, не меняя их суммы (OQ-149).
- План не создаёт денежный факт. Один контур учитывается один раз в день; явно разные дневной/ночной контуры суммируются. Месячная модель и ручные итоговые значения сохраняются.
