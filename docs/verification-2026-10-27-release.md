## Применение

Релиз `dcf22db` успешно применён. Остановлен только backend на окно обновления; сохранён ещё один свежий dump без записей приложения. Именно финальная копия также восстановлена в отдельную БД с 95 завершёнными миграциями, затем проверочная БД удалена. Контрольные суммы финального dump, globals и конфигурации повторно проверены после запуска.

Штатный `prisma migrate deploy` успешно применил три новые миграции; в production теперь 98 завершённых миграций, незавершённых нет. Backend и frontend заменены последовательно, оба healthy, фактические image IDs сверены с релизными тегами, рестартов после старта — 0. DNS, Caddy/TLS-конфигурация, PostgreSQL/MinIO/Redis volumes не менялись; seed не запускался. Старые копии и rollback-образы сохранены. Свободно около 17 ГиБ.

Особенность исполнения: миграционный `compose run` забрал stdin управляющей оболочки после успешной миграции. Запуск backend/frontend завершён отдельной командой; в операционном helper отключён interactive stdin. Результат проверен отдельно по контейнерам, образам, HTTP и чтению БД. Автоматический возврат образов на production специально не тестировался, рабочая БД из бэкапа не восстанавливалась.
